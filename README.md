# המערכת האישית שלי

מערכת שעות אישית למדריכי טכני חיפה. האתר סורק את מערכת השעות של בית הספר
(https://techni.shahaf.site/) כל 20 דקות בימי לימודים, 07:00–14:40, ובונה לכל מדריך דף אישי:
השיעור הנוכחי והבא, לפי יום, שבוע מלא, כיתות, תורני חצר, מבחנים ואירועים, ויומן שינויים.

האתר נפתח בעמוד הראשי (רשימת הצוותים). טלפון שקושר למדריך ("הפעלת התראות וקישור הטלפון") נפתח ישר על
המערכת שלו; `?main` בכתובת פותח תמיד את העמוד הראשי.

## החלקים
- **גיליון הניהול** (גוגל שיטס): אנשי צוות (כולל "התמחות", ומנהלי תחום לפי "תפקיד"), צוותים (כולל "מפקד"),
  תוספות. שורה בתוספות על שם קבוצה ("צוות ט", "מגמת חשמל", "מפקדים", "מנהלים", "מנהלים ומפקדים") נכנסת לכל
  הקבוצה. `tracks.json`, `managers.json` ו-`extras.json` בגיטהאב הם גיבוי כשהגיליון לא מגדיר את אלה.
- `tracker/build.py`: סורק את שחף, קורא את הגיליון ובונה את `docs/data/`: דף לכל מדריך, כיתות, תורני חצר
  (`duty.json`), היסטוריית תורנויות (`duty_history.json`) ודוחות חודשיים (`duty_reports.json`).
- `tracker/push.py` (+ `tracker/notify_text.py` לניסוח): שולח התראות לטלפונים: סיכום בוקר, שינויים להיום,
  התראה 15–35 דקות לפני כל שיעור (אפשר לכבות), תזכורות ותורנויות בשעה הקרובה, סיכום צוות למפקדים, ודוח
  תורנויות בסוף החודש. כל הודעה נרשמת כנשלחה לכל טלפון בנפרד (`docs/data/push_log.json`, מוצפן).
- `web/index.html`: האתר עצמו. GitHub Pages מפרסם את `docs/`.
- `apps-script/Code.gs`: **המנוע** (Google Apps Script בחשבון היחידה). שומר בגיליון פרטי את התזכורות,
  את הקישור של כל מדריך לטלפון (או לכמה דפדפנים), את המנויים להתראות, את השינויים הידניים בתורני חצר
  ושורה ליום של כניסות. ב־Apps Script מודבק רק `apps-script/Loader.gs`, שטוען את Code.gs מגיטהאב בכל ריצה,
  כך ששינוי במנוע לא דורש הדבקה.
- `.github/workflows/update.yml`: העדכון השעתי. טיימר ב-cron-job.org מפעיל אותו.
  `check-api.yml` בודק שהמנוע עונה.

## תורני חצר
כל בוקר נבנית רשימה לכל שכבה: לכל שעה שהשכבה לומדת, מדריך פנוי אחד מהצוות שלה, ובהפסקה הגדולה
שני תפקידים. כל שעה הולכת לפנוי שעשה הכי מעט תורנויות החודש (טבלת צדק), ולא למי שיש לו תורנות בשעה
הסמוכה, כל עוד יש מישהו אחר פנוי. כל איש צוות (מהטלפון
המקושר אליו, רק בשכבות של הצוות שלו), וגם מפקדים ואנשי מנהלה (עם קוד), יכולים לשנות שורה ידנית עם
הערה, והעדכון השעתי שומר את השינוי.

## שחרורי כיתות
עם תורני החצר נבנה גם מי משחרר כל כיתה בסוף היום: מדריך/ת הכיתה אם פנוי/ה, אחרת מדריך פנוי מצוות השכבה
לפי טבלת צדק נפרדת. מי שמישהו ממלא את מקומו באותו יום נחשב נעדר ולא משובץ לתורנות או לשחרור.

## קודים
- מדריכים: בלי קוד. הטלפון מקושר כשמפעילים התראות, ומקבל קוד שחזור אישי (נשמרת רק טביעה שלו, בלשונית
  "שחזור") שמקשר טלפון חדש בלי עזרה.
- ראשי צוות, מפקדים ומנהלי תחום: קוד משותף. באתר נשמרת רק "טביעה" שלו (`config.json`), והמנוע בודק אותו מול
  "קוד מפקדים" בגיליון הפרטי.
- אנשי מנהלה: קוד בגיליון הפרטי בלבד ("קוד אנשי מנהלה").

## סודות בגיטהאב
- `PUSH_TOKEN`: "מפתח התראות" מהגיליון הפרטי.
- `VAPID_PRIVATE_KEY`: החצי הפרטי של מפתח ההתראות. החצי הציבורי נמצא ב-`config.json`.

בלי שני הסודות האתר עובד כרגיל, אבל לא נשלחות התראות.

## הרצה ידנית
```
python3 tracker/build.py            # סריקה ובנייה
python3 tracker/build.py --offline  # בנייה מחדש בלי סריקה
```
